# 品曜 AI

电商商品视觉创作桌面软件。

本仓库仅用于发布安装包与版本说明，不包含项目源码，不保存用户素材或模型密钥。

## Windows 下载

当前测试版：**0.1.11**，Windows x64。

[下载安装包](https://github.com/Doifi/pinyao-ai-releases/releases/download/v0.1.11/pinyao-ai-setup-0.1.11.exe)

[版本说明与文件校验值](https://github.com/Doifi/pinyao-ai-releases/releases/tag/v0.1.11)

首次使用需要自行配置模型服务商的接口地址、模型名称和 API Key。模型密钥加密保存在本机；执行生成任务时，必要的提示词与参考素材会发送至用户配置的模型服务商。模型调用费用由用户与服务商结算。
